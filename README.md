# モダンポジティブ小倉百人一首

            これは作業用スクリーンセーバーwebアプリ。

            百人一首を学び楽しみたい。だけど現代に伝わる一般的な解釈は、ことさらに言葉の裏を想像してメランコリックになったり厭世的になったり、ネガティブなものが多すぎる。
            
            よいではないですか、この素晴らしい文学からポジティブなニュアンスだけ摂取しても。もしかしたら詠んだ当人だって、そこまで後ろ向きなニュアンスは意図してなかったのかもしれないよ。自己肯定感高めのこの令和の時代。AIに小倉百人一首を前向きに解釈してもらって、晴れやかに楽しもう！
            
            ※学術的正しさは一切ございません🙏
            
            ※和歌の「一般的な解釈」は全日本かるた協会ウェブサイトから引用しています。
